# GeoGalicia: Roteiro Lab Atlántico

Página de instrucciones del proyecto **GeoGalicia: Roteiro Lab Atlántico**,
un geoart colaborativo de geocaching en el que **29 equipos** crean
**61 Adventure Labs** que, unidos, dibujan la palabra **GALICIA** sobre
el Atlántico, frente a la costa noroeste de Galicia.

Esta página reúne, de forma sencilla para todos los participantes:

- el mapa del geoart con los 61 puntos y sus coordenadas en formato geocaching;
- las instrucciones paso a paso para crear cada Adventure Lab y sus 5 etapas;
- los datos comunes del proyecto (nombre, descripción, imagen de portada,
  propuesta de coordenadas de las etapas, votaciones…).

Está construida con HTML, CSS y JavaScript, con mapas de
[Leaflet](https://leafletjs.com/) (OpenStreetMap y vista de satélite),
y se publica a través de **GitHub Pages**.
